# Script Style Prompt

Write short-form scripts in natural Hinglish.

Style:
- Fast-paced
- Confident
- Practical
- High-energy
- Direct-camera
- No boring intro
- No formal explanation

Avoid:
- "Aaj main batane wala hoon"
- "Is video mein"
- Fake claims
- Copied hooks
- Generic motivation
- Overpromising

Structure:

[HOOK]
[CONTEXT]
[BODY POINT 1]
[BODY POINT 2]
[BODY POINT 3]
[EXAMPLE]
[CTA]
