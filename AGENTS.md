# Trend-to-Niche Content Agent System

## Project Goal

This project builds a multi-agent content research and script generation system.

The system must:
1. Find trending topics from multiple platforms.
2. Identify viral hooks from big creators.
3. Analyze why hooks worked.
4. Align trends and hooks with our channel niche.
5. Generate hook + body + CTA.
6. Verify the final output before delivery.

## Channel Style

Language: Natural Hinglish
Tone: fast-paced, confident, practical, high-energy, direct-camera
Style: short-form Instagram Reels / YouTube Shorts
Avoid: formal language, generic scripts, fake claims, copied hooks, boring explanations

## Core Rule

Never copy a creator directly. Extract the pattern, then adapt it to our niche.

## Output Standard

Every final output must include:

1. Trending topic
2. Why it is trending
3. Original viral hook pattern
4. Adapted hooks
5. Niche alignment explanation
6. Full script body
7. CTA options
8. Verification report
9. Recommended best version

## Verification Rule

Before final output, always run the verifier agent.

The verifier must check:
- Is the trend actually relevant?
- Is the hook copied or safely adapted?
- Is the hook speakable in under 4 seconds?
- Is the script aligned with our channel?
- Are claims safe and not misleading?
- Is the CTA clear?
- Is the first 2-second visual opening strong?
